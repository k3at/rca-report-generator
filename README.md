# RCA Report Generator

Root Cause Analysis report generator (web app). Fill structured fields → generate report → print/PDF.

## Features
- 6 RCA models: 5 Whys, Fishbone (6M), 8D, A3, FMEA, Fault Tree
- One-click report generation
- PDF export (jsPDF) + print
- Save/Load (localStorage)
- Model comparison & recommendation

## Run locally
Open `index.html` in a browser. No build needed.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Push this folder to `main`.
3. Repo Settings → Pages → Source: GitHub Actions.
4. The workflow deploys automatically.

## Free hosting alternatives
- Netlify Drop (drag `index.html`)
- Vercel / Cloudflare Pages
